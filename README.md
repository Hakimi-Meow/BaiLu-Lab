## 安卓版

- 最新：`apk/BaiLuPet-v1.27.apk`
  https://github.com/Hakimi-Meow/BaiLu-Lab/raw/main/apk/BaiLuPet-v1.27.apk
- 旧版：`apk/BaiLuPet-v1.0.apk`
- 摸猫计数 + 桌面悬浮宠物，点她会冒气泡说话

### v1.27 功能

- 桌面悬浮宠物：拖动、点击说话、长按菜单、三档大小
- 实时更新通知：好感 / 饱食 / 摸摸次数
- 养成存档、离线结算、整点报时、开机自启
- 久坐提醒、低电量提醒
- 纪念日、心情日记、今日统计
- 桌面时钟（画在桌宠身上，跟着走）
- 白噪音（本地合成雨声）
- 换装四配色、自定义台词、长按菜单可勾选
- 全面屏适配、半透明头像水印
